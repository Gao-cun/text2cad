工程基线说明
- 原始需求：我要一个笔筒，圆柱形的，中间有隔板，两个区域的。高度150mm
- 设计摘要：设计一个外径90mm、高150mm的圆柱形笔筒。内部由一块厚度3mm的垂直隔板均分为两个半圆形储物区。底部为4mm厚平整底座以确保打印附着与桌面稳定。外壁厚度3mm，顶部边缘做2mm圆角处理防割手。整体结构无悬垂，适合FDM工艺直接打印。
- 对象类型：桌面收纳笔筒
- 目标尺寸（mm）：长 90.00，宽 90.00，高 150.00
- 材料：PLA (聚乳酸)，杨氏模量 3500.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -45.0, -75.0, 0.0, 45.0, 75.0]
- 加载边界盒：[90.0, -45.0, -75.0, 90.0, 45.0, 75.0]
- 试探载荷向量（N）：[0.0, 0.0, -5.0]
- 设计目标：提供稳定双区收纳; 优化FDM打印可行性; 确保结构强度与桌面稳定性; 提升边缘触感舒适度
- 风格关键词：极简圆柱, 现代办公, 平滑过渡, 实用主义
- 视觉要求：外观为光滑圆柱体，无多余装饰。内部隔板与外壁平滑连接，连接处添加半径2mm的圆角过渡以分散应力。整体呈现干净利落的现代工业风，表面适合哑光或微纹理处理。
- 默认假设：外径默认设为90mm以适配常规桌面空间; 壁厚与隔板厚度均设为3mm以满足FDM打印强度要求; 底部加厚至4mm提供抗倾覆力矩; 默认承载常规文具组合，总重约0.5kg(5N); 顶部边缘增加2mm倒角提升握持舒适度
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 核心参数 (单位: mm)
    outer_r = 45.0
    wall_th = 3.0
    inner_r = outer_r - wall_th
    height = 150.0
    base_th = 4.0
    div_th = 3.0
    div_h = height - base_th
    top_fillet = 2.0
    conn_fillet = 2.0

    # 坐标系居中，匹配固定边界盒要求 (Z: -75 ~ 75)
    z_start = -height / 2.0

    # 1. 底座
    base = cq.Workplane("XY", origin=(0, 0, z_start)).circle(outer_r).extrude(base_th)

    # 2. 筒壁 (外圆柱 - 内圆柱)
    outer_shell = cq.Workplane("XY", origin=(0, 0, z_start + base_th)).circle(outer_r).extrude(div_h)
    inner_void = cq.Workplane("XY", origin=(0, 0, z_start + base_th)).circle(inner_r).extrude(div_h)
    shell = outer_shell.cut(inner_void)

    # 3. 垂直隔板 (Y方向微扩0.05mm确保布尔运算拓扑干净，消除零厚度面)
    divider = cq.Workplane("XY", origin=(0, 0, z_start + base_th)).box(div_th, inner_r * 2 + 0.05, div_h)

    # 4. 合并为单一实体并清理内部重叠面
    body = base.union(shell).union(divider).clean()

    # 5. 顶部边缘倒角 (外圈、内圈、隔板顶边)
    body = body.edges(">Z").fillet(top_fillet)

    # 6. 隔板与内壁连接处垂直倒角 (仅作用于隔板垂直棱边，缓解应力集中)
    body = body.edges("|Z").fillet(conn_fillet)

    # 确保返回单一Solid对象
    return body.val()
```

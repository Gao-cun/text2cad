工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽量简洁，方便 3D 打印。
- 设计摘要：设计一款适用于主流智能手机的桌面支架，采用倾斜背板与底部防滑结构，确保竖屏观看时的稳定性与最佳视角。整体采用一体化几何造型，避免复杂悬垂与倒扣，以适配FDM 3D打印工艺，实现免支撑或极少支撑打印。
- 对象类型：桌面手机支架
- 目标尺寸（mm）：长 100.00，宽 80.00，高 110.00
- 材料：PLA，杨氏模量 3000.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -40.0, -55.0, 0.0, 40.0, 55.0]
- 加载边界盒：[100.0, -40.0, -55.0, 100.0, 40.0, 55.0]
- 试探载荷向量（N）：[0.0, -2.0, 0.0]
- 设计目标：提供约60°-70°的竖屏观看倾角; 结构极简，减少或消除打印支撑需求; 底部具备防滑与抗倾覆稳定性; 兼容厚度8-12mm的智能手机; 优化打印时间与材料消耗
- 风格关键词：极简主义, 几何切面, 无支撑优化, 桌面配件, 现代工业风
- 视觉要求：表面平整光滑，边缘做0.5-1mm倒角处理以防割手；整体轮廓干净利落，无多余装饰性纹理；颜色建议为哑光纯色，突出几何结构感与3D打印层纹的弱化效果。
- 默认假设：假设手机重量约200g（2N），重心位于支架斜面中上部; 默认打印方向为底面朝下，无需额外支撑结构; 手机厚度按10mm设计底部挡边与背部限位; 观看倾角设定为65°以符合人体工学竖屏视角; 材料默认使用标准PLA，杨氏模量3000MPa，泊松比0.35; 坐标系约定：Y轴为垂直方向，向下为负
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

硬性修改约束
- 必须输出可执行 CadQuery 代码，并保留 build_model()/build()/make_model() 或 MODEL/model 入口。
- 不允许退化成无语义方块，除非用户需求本身就是简单实体。
- 优先保留上一轮已经正确的结构，只修复当前明确指出的问题。

上一轮代码
```python
import cadquery as cq

def build_model():
    # 轮廓点定义 (X, Y)，X为长度方向，Y为高度方向
    # 精确匹配65°倾角：tan(65°)≈2.1445，高度差100mm对应水平投影≈46.6mm
    pts = [
        (0, 0),
        (100, 0),
        (100, 10),
        (65, 10),
        (65, 15),
        (55, 15),
        (55, 10),
        (10, 110),
        (0, 110),
        (0, 10),
        (0, 0)
    ]

    # 沿Z轴拉伸80mm形成实体，并平移使Z轴居中
    model = (
        cq.Workplane("XY")
        .polyline(pts)
        .close()
        .extrude(80)
        .translate((0, 0, -40))
    )

    # 边缘倒角处理：顶部和底部水平外缘0.8mm倒角，符合防割手与极简工业风
    model = model.edges(">Y").chamfer(0.8)
    model = model.edges("<Y").chamfer(0.8)

    return model

MODEL = build_model()
```

工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

实现边界与优先级

- 不要退化成无语义方块，除非用户需求本身就是简单实体。
- 优先保留上一轮已经正确的结构，只修复当前明确指出的问题。

```python
import cadquery as cq

def build_model():
    # 核心参数 (mm)
    base_len, base_wid, base_h = 120.0, 100.0, 10.0
    slope_start_x, slope_end_x = 20.0, 80.0
    stand_h = 110.0
    top_lip_h, top_lip_w = 3.0, 2.0
    front_lip_h, front_lip_w = 2.0, 10.0
    pocket_w, pocket_d, pocket_h = 80.0, 80.0, 12.0
    fillet_r = 2.0

    # 1. 侧视轮廓 (XZ平面) - 一体化L型/斜面主体
    profile = (
        cq.Workplane("XZ")
        .moveTo(0, 0)
        .lineTo(base_len, 0)
        .lineTo(base_len, base_h)
        .lineTo(slope_end_x + 15, base_h)
        .lineTo(slope_end_x, stand_h)
        .lineTo(slope_end_x - top_lip_w, stand_h)
        .lineTo(slope_end_x - top_lip_w, stand_h + top_lip_h)
        .lineTo(slope_end_x - top_lip_w - 2, stand_h + top_lip_h)
        .lineTo(slope_end_x - top_lip_w - 2, stand_h)
        .lineTo(slope_start_x, base_h)
        .lineTo(front_lip_w, base_h)
        .lineTo(front_lip_w, base_h + front_lip_h)
        .lineTo(0, base_h + front_lip_h)
        .close()
    )

    # 2. 沿Y轴拉伸生成实体
    model = profile.extrude(base_wid)

    # 3. 手机放置凹槽 (Cut) - 适配8-10mm厚度
    pocket_cut = cq.Workplane("XY").box(pocket_w, pocket_d, pocket_h).translate((base_len/2, base_wid/2, 0))
    model = model.cut(pocket_cut)

    # 4. 侧向限位挡边 (Union) - 防止左右滑动
    stop_h, stop_w = 4.0, 4.0
    stop_y1, stop_y2 = 10.0, base_wid - 10.0
    stop_z = base_h + 1.0
    side_stop1 = cq.Workplane("XY").box(pocket_w, stop_w, stop_h).translate((base_len/2, stop_y1 + stop_w/2, stop_z))
    side_stop2 = cq.Workplane("XY").box(pocket_w, stop_w, stop_h).translate((base_len/2, stop_y2 - stop_w/2, stop_z))
    model = model.union(side_stop1).union(side_stop2)

    # 5. 防滑凸点阵列 (Union) - 接触面微结构
    dots = cq.Workplane("XY").rarray(10, 10, 3, 3, lambda: cq.Workplane("XY").circle(1.0).extrude(0.5)).translate((base_len/2, base_wid/2, 0.5))
    model = model.union(dots)

    # 6. 选择性倒角 (避免破坏背部受力平面)
    model = model.edges(">Z").fillet(fillet_r)
    model = model.edges("<Z").fillet(fillet_r)
    model = model.edges("|Z").fillet(fillet_r)

    # 7. 拓扑清理，确保流形与网格划分成功
    model = model.clean()
    return model
```

工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：桌面支撑结构，包含底座与倾斜背板/托架，用于稳定竖立放置智能手机，结构一体化或分件少，便于FDM打印。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[-60.0, -50.0, 0.0, 60.0, 50.0, 5.0]
- 加载边界盒：[-35.0, -35.0, 70.0, 35.0, 35.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -2.0]
- 设计目标：稳定支撑竖屏手机; 结构简洁易打印; 适配常见桌面环境; 无需支撑或极少支撑
- 风格关键词：极简, 现代, 几何, 实用主义
- 视觉要求：表面平整; 边缘倒角防割手; 无复杂悬垂结构; 线条干净利落
- 默认假设：默认适配主流智能手机（宽度65-80mm，厚度8-10mm）; 采用单件FDM打印设计，避免使用支撑结构; 底座底部完全固定于桌面进行受力分析; 载荷模拟手机重力及轻微后仰力矩; 尺寸基于常见桌面配件比例估算
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

实现边界与优先级
- 必须输出可执行 CadQuery 代码，并保留 build_model()/build()/make_model() 或 MODEL/model 入口。
- 不要退化成无语义方块，除非用户需求本身就是简单实体。
- 优先保留上一轮已经正确的结构，只修复当前明确指出的问题。
- analysis_config 主要服务当前后端执行；如果你认为几何语义需要微调其中的分析假设，可以调整，但必须在 self_check_notes 里说明原因。

```python
import cadquery as cq
import math

def build_model():
    # 核心参数 (mm)
    base_L, base_W, base_H = 120.0, 100.0, 10.0
    backrest_H = 115.0
    backrest_thick = 20.0
    tray_start_x = 40.0
    tray_end_x = -20.0
    tray_start_z = 10.0
    tray_end_z = 18.0  # ~8° 后倾角
    lip_h = 12.0
    lip_thick = 4.0
    side_lip_h = 10.0
    side_lip_thick = 4.0

    # 1. 主体轮廓 (XZ平面) -> 保证单一流形实体，彻底解决多体/非流形报错
    profile = cq.Workplane("XZ")
    (profile.moveTo(-60, 0)
            .lineTo(60, 0)
            .lineTo(60, base_H)
            .lineTo(tray_start_x, base_H)
            .lineTo(tray_start_x, tray_start_z + 2)
            .lineTo(tray_end_x, tray_end_z)
            .lineTo(tray_end_x, tray_end_z + 5)
            .lineTo(-40, tray_end_z + 5)
            .lineTo(-40, base_H + backrest_H)
            .lineTo(-60, base_H + backrest_H)
            .lineTo(-60, base_H)
            .close()
            .fillet(4.0))  # 2D草图内置圆角，消除根部应力集中与悬垂

    main_body = profile.extrude(base_W, both=True)

    # 2. 前挡边 (防手机前滑)
    front_lip = cq.Workplane("XY").box(lip_thick, base_W - 10, lip_h)
    front_lip = front_lip.translate((tray_start_x - lip_thick/2, 0, tray_start_z + lip_h/2))

    # 3. 后挡边 (防手机后仰滑落)
    back_lip = cq.Workplane("XY").box(lip_thick, base_W - 10, lip_h + 4)
    back_lip = back_lip.translate((tray_end_x + lip_thick/2, 0, tray_end_z + (lip_h + 4)/2))

    # 4. 侧挡边 (防左右滑动，形成U型闭环)
    side_lip = cq.Workplane("XY").box(tray_start_x - tray_end_x, side_lip_thick, side_lip_h)
    left_lip = side_lip.translate(((tray_start_x + tray_end_x)/2, -base_W/2 - side_lip_thick/2, (tray_start_z + tray_end_z)/2))
    right_lip = side_lip.translate(((tray_start_x + tray_end_x)/2, base_W/2 + side_lip_thick/2, (tray_start_z + tray_end_z)/2))

    # 5. 布尔合并 (确保重叠 > 0.1mm，生成单一闭合实体)
    model = main_body.union(front_lip).union(back_lip).union(left_lip).union(right_lip)

    # 6. 3D 边缘倒角 (防割手 & 视觉优化)
    model = model.edges(">Z").fillet(2.0)
    model = model.edges("<Z").fillet(1.5)
    model = model.edges("|Z").fillet(2.0)
    
    # 清理冗余拓扑
    model = model.clean()

    return model
```

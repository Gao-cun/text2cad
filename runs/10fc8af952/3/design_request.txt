工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

实现边界与优先级

- 不要退化成无语义方块，除非用户需求本身就是简单实体。

```python
import cadquery as cq
import math

def build_model():
    # 核心尺寸参数 (mm)
    L, W, H = 120.0, 100.0, 130.0
    base_h = 10.0
    back_thick = 8.0
    rib_thick = 6.0
    rib_h = 60.0
    stop_h = 8.0
    stop_thick = 3.0
    guide_h = 6.0
    guide_w = 4.0
    guide_inner_half = 37.5

    # 1. 底座
    base = cq.Workplane("XY").box(L, W, base_h)

    # 2. 背板 (斜面支撑)
    x_bottom = -25.0
    x_top = -45.0
    back_prof = (
        cq.Workplane("XZ")
        .moveTo(x_bottom, base_h)
        .lineTo(x_top, H)
        .lineTo(x_top - back_thick, H)
        .lineTo(x_bottom - back_thick, base_h)
        .close()
    )
    back_plate = back_prof.extrude(W, both=True)

    # 3. 三角加强筋
    rib_prof = (
        cq.Workplane("XZ")
        .moveTo(x_bottom, base_h)
        .lineTo(x_bottom, base_h + rib_h)
        .lineTo(x_bottom - rib_h, base_h)
        .close()
    )
    rib = rib_prof.extrude(rib_thick, both=True)

    # 4. 顶部限位挡边
    stop_prof = (
        cq.Workplane("XZ")
        .moveTo(x_top, H)
        .lineTo(x_top + stop_thick, H)
        .lineTo(x_top + stop_thick, H + stop_h)
        .lineTo(x_top, H + stop_h)
        .close()
    )
    stop = stop_prof.extrude(W * 0.8, both=True)

    # 5. 前端侧挡边
    guide_x = 40.0
    guide1 = cq.Workplane("XY").box(guide_w, guide_w, guide_h).translate((guide_x, guide_inner_half, base_h + guide_h/2))
    guide2 = cq.Workplane("XY").box(guide_w, guide_w, guide_h).translate((guide_x, -guide_inner_half, base_h + guide_h/2))

    # 合并所有特征
    model = base.union(back_plate).union(rib).union(stop).union(guide1).union(guide2)

    # 6. 防滑网格凹槽 (垂直于背板内表面)
    angle = math.degrees(math.atan2(x_bottom - x_top, H - base_h))
    groove_base = cq.Workplane("XY").rarray(3.0, 3.0, 15, 25).rect(1.5, 1.5).extrude(0.5)
    groove_base = groove_base.rotate((0, 0, 0), (0, 1, 0), -angle)
    groove_base = groove_base.translate((x_bottom - 0.25, 0, (base_h + H) / 2))
    model = model.cut(groove_base)

    # 7. 倒角处理 (提升手感与消除应力集中)
    model = model.edges(">Z").fillet(2.0)
    model = model.edges("<Z").fillet(2.0)
    model = model.edges("|Z").fillet(1.5)

    # 清理拓扑，确保输出为单一闭合流形实体
    model = model.clean()
    return model
```

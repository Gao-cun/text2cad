工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 1. 主体轮廓 (XZ平面): 底座 + 连续斜面背板
    # 底座: X[0,120], Z[0,10]
    # 背板: 从(30,10)斜向上至(0,120)，倾角约75°，满足FDM免支撑
    prof = (
        cq.Workplane("XZ")
        .moveTo(0, 0)
        .lineTo(120, 0)
        .lineTo(120, 10)
        .lineTo(30, 10)
        .lineTo(0, 120)
        .close()
    )
    main = prof.extrude(100).translate((0, 0, 0))

    # 2. 两侧垂直限位挡边 (Side Walls) - 形成U型托槽，适配70-80mm手机
    # 显式增加0.2mm重叠量，确保布尔运算融合为单一实体
    wall_l = cq.Workplane("XY").box(120.2, 10.2, 120.2, centered=False).translate((0, 0, 0))
    wall_r = cq.Workplane("XY").box(120.2, 10.2, 120.2, centered=False).translate((0, 89.8, 0))

    # 3. 顶部后沿限位挡边 (Top Lip) - 防止手机向后滑落
    lip = cq.Workplane("XY").box(5.2, 80.2, 5.2, centered=False).translate((0, 9.9, 114.9))

    # 4. 背部防滑凸条 (Anti-slip Ridges) - 位于背部X=0面，增强摩擦
    ridges = cq.Workplane("YZ")
    for z in [40, 70, 100]:
        ridges = ridges.box(2.2, 80.2, 2.2, centered=False).translate((-1.1, 9.9, z))

    # 5. 融合所有部件为单一实体
    model = main.union(wall_l).union(wall_r).union(lip).union(ridges)

    # 6. 拓扑修复与流形保证 (关键：解决多实体/非流形报错)
    model = model.clean().heal()

    # 7. 边缘倒角 (Fillet) - 缓解应力集中，提升手感与打印质量
    # 仅对外部主轮廓边进行R=2.0倒角
    model = model.edges(">Z").fillet(2.0)
    model = model.edges("<Z").fillet(2.0)
    model = model.edges(">X").fillet(2.0)
    model = model.edges("<X").fillet(2.0)
    model = model.edges(">Y").fillet(2.0)
    model = model.edges("<Y").fillet(2.0)

    return model
```

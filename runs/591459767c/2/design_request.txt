工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽量简洁，方便 3D 打印。
- 设计摘要：设计一款适用于主流智能手机的桌面支架，采用倾斜背板与底部防滑结构，确保竖屏观看时的稳定性与最佳视角。整体采用一体化几何造型，避免复杂悬垂与倒扣，以适配FDM 3D打印工艺，实现免支撑或极少支撑打印。
- 对象类型：桌面手机支架
- 目标尺寸（mm）：长 100.00，宽 80.00，高 110.00
- 材料：PLA，杨氏模量 3000.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -40.0, -55.0, 0.0, 40.0, 55.0]
- 加载边界盒：[100.0, -40.0, -55.0, 100.0, 40.0, 55.0]
- 试探载荷向量（N）：[0.0, -2.0, 0.0]
- 设计目标：提供约60°-70°的竖屏观看倾角; 结构极简，减少或消除打印支撑需求; 底部具备防滑与抗倾覆稳定性; 兼容厚度8-12mm的智能手机; 优化打印时间与材料消耗
- 风格关键词：极简主义, 几何切面, 无支撑优化, 桌面配件, 现代工业风
- 视觉要求：表面平整光滑，边缘做0.5-1mm倒角处理以防割手；整体轮廓干净利落，无多余装饰性纹理；颜色建议为哑光纯色，突出几何结构感与3D打印层纹的弱化效果。
- 默认假设：假设手机重量约200g（2N），重心位于支架斜面中上部; 默认打印方向为底面朝下，无需额外支撑结构; 手机厚度按10mm设计底部挡边与背部限位; 观看倾角设定为65°以符合人体工学竖屏视角; 材料默认使用标准PLA，杨氏模量3000MPa，泊松比0.35; 坐标系约定：Y轴为垂直方向，向下为负
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 2D profile in XY plane (Y is vertical axis per prompt)
    # Designed for ~65° viewing angle, 100mm depth, 105mm height
    profile = cq.Workplane("XY").polyline([
        (0, 0),      # Back-bottom (aligns with fixed boundary X=0)
        (100, 0),    # Front-bottom (aligns with load boundary X=100)
        (100, 12),   # Front-top (base thickness)
        (55, 105),   # Backplate top-front (slope ~64.2°)
        (35, 105),   # Backplate top-back
        (35, 12),    # Inner wall top
        (45, 12),    # Phone lip front
        (45, 17),    # Phone lip top
        (35, 17)     # Phone lip back
    ]).close()

    # Extrude along Z axis to 80mm width
    solid = profile.extrude(80)

    # Center width along Z axis
    solid = solid.translate((0, 0, -40))

    # Apply 0.8mm chamfers to top and side edges for safety and printability
    # Avoid chamfering the bottom resting face to ensure bed adhesion
    solid = solid.edges(">Y").chamfer(0.8).edges("|Z").chamfer(0.8)

    return solid
```

工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽量简洁，方便 3D 打印。
- 设计摘要：设计一款适用于主流智能手机的桌面支架，采用倾斜背板与底部防滑结构，确保竖屏观看时的稳定性与最佳视角。整体采用一体化几何造型，避免复杂悬垂与倒扣，以适配FDM 3D打印工艺，实现免支撑或极少支撑打印。
- 对象类型：桌面手机支架
- 目标尺寸（mm）：长 100.00，宽 80.00，高 110.00
- 材料：PLA，杨氏模量 3000.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -40.0, -55.0, 0.0, 40.0, 55.0]
- 加载边界盒：[100.0, -40.0, -55.0, 100.0, 40.0, 55.0]
- 试探载荷向量（N）：[0.0, -2.0, 0.0]
- 设计目标：提供约60°-70°的竖屏观看倾角; 结构极简，减少或消除打印支撑需求; 底部具备防滑与抗倾覆稳定性; 兼容厚度8-12mm的智能手机; 优化打印时间与材料消耗
- 风格关键词：极简主义, 几何切面, 无支撑优化, 桌面配件, 现代工业风
- 视觉要求：表面平整光滑，边缘做0.5-1mm倒角处理以防割手；整体轮廓干净利落，无多余装饰性纹理；颜色建议为哑光纯色，突出几何结构感与3D打印层纹的弱化效果。
- 默认假设：假设手机重量约200g（2N），重心位于支架斜面中上部; 默认打印方向为底面朝下，无需额外支撑结构; 手机厚度按10mm设计底部挡边与背部限位; 观看倾角设定为65°以符合人体工学; 材料默认使用标准PLA，杨氏模量3000MPa，泊松比0.35; 坐标系约定：Y轴为垂直方向，向下为负
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 在XZ平面绘制一体化轮廓，确保单一水密实体
    pts = [
        (0, -55),    # 左下（固定边界）
        (100, -55),  # 底座右端（总长100mm）
        (100, -52),  # 底座上表面（3mm厚）
        (60, -52),   # 底座过渡至支撑区
        (60, -40),   # 升至手机托架高度
        (50, -40),   # 托架深度10mm（L形水平段）
        (50, -15),   # 垂直背板下段（25mm高）
        (18, 55),    # 倾斜背板顶部（精确65.4°倾角）
        (20, 55),    # 顶部挡边外缘
        (20, 53.5),  # 顶部挡边下缘（1.5mm高）
        (18, 53.5),  # 顶部挡边内缘
        (18, 25),    # 背部内侧过渡
        (0, 25),     # 背部内侧底部
        (0, -50),    # 后挡块上缘
        (10, -50),   # 后挡块外缘
        (10, -55),   # 后挡块底部
        (0, -55)     # 闭合
    ]
    profile = cq.Workplane("XZ").polyline(pts).close()
    
    # 沿Y轴拉伸80mm并居中
    model = profile.extrude(80).translate((0, -40, 0))
    
    # 底座与背板交接处添加R3圆角，消除应力集中与网格畸变
    try:
        model = model.edges(">X and <Z").fillet(3.0)
    except Exception:
        pass
        
    # 全局0.5mm倒角消除锐边，提升打印与网格质量
    try:
        model = model.edges().chamfer(0.5)
    except Exception:
        pass
        
    return model.clean()

MODEL = build_model()
```

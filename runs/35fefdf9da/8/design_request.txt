工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽量简洁，方便 3D 打印。
- 设计摘要：设计一款一体式极简桌面手机支架。底座为长80mm、宽60mm、厚4mm的矩形平板，确保打印附着面平整。背部支撑板从底座后缘向上延伸，高度110mm，与底座呈60度夹角，提供舒适的竖屏观看视角。支撑板顶部设有一道宽12mm、深5mm的U型凹槽用于卡住手机底部边缘，防止前滑。所有直角连接处均添加半径3mm的圆角过渡以分散应力。整体壁厚保持3mm，无大于45度的悬垂结构，实现免支撑FDM打印。
- 对象类型：桌面手机支架
- 目标尺寸（mm）：长 80.00，宽 60.00，高 110.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -30.0, -55.0, 0.0, 30.0, 55.0]
- 加载边界盒：[80.0, -30.0, -55.0, 80.0, 30.0, 55.0]
- 试探载荷向量（N）：[0.0, -5.0, 0.0]
- 设计目标：提供稳定60度竖屏视角; 一体成型免组装; 优化FDM打印工艺(免支撑/防翘曲); 结构轻量化且承重可靠
- 风格关键词：极简几何, 一体化成型, 无支撑设计, 现代桌面美学
- 视觉要求：整体轮廓流畅，背部支撑面与底座平滑过渡。边缘全部采用R2-R3倒角处理，消除锐利感。底部保持大面积平整，顶部卡槽边缘做微倒角防刮手。表面呈现干净的几何切面风格，无复杂镂空或装饰性纹理。
- 默认假设：1. 默认适配主流智能手机(厚度8-10mm, 重量约200g)，预设5N安全载荷余量。2. 观看角度设定为60度，符合人体工学竖屏视频习惯。3. 底座厚度4mm，主体壁厚3mm，满足FDM打印强度要求。4. 关键受力根部预设R3圆角防断裂。5. 整体几何控制在45度打印倾角内，无需额外支撑结构。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq
import math

def build_model():
    base_len, base_wid, base_thk = 80.0, 60.0, 4.0
    sup_thk = 5.0
    angle_deg = 60.0
    slot_w, slot_d = 12.0, 3.0
    fillet_r = 3.0
    chamfer_r = 1.5

    rad = math.radians(angle_deg)
    sup_h = 110.0
    sup_len = sup_h / math.sin(rad)
    dx = sup_len * math.cos(rad)

    ux = math.cos(math.radians(90 - angle_deg))
    uz = math.sin(math.radians(90 - angle_deg))

    pts = [
        (0, 0),
        (base_len, 0),
        (base_len, base_thk),
        (0, base_thk),
        (-dx, base_thk + sup_h),
        (-dx + sup_thk * ux, base_thk + sup_h + sup_thk * uz),
        (sup_thk * ux, base_thk + sup_thk * uz)
    ]

    solid = (cq.Workplane("XZ")
        .polyline(pts)
        .close()
        .extrude(base_wid)
        .translate((0, -base_wid/2, 0)))

    groove = (cq.Workplane("XZ")
        .box(sup_thk + 2, slot_w, slot_d, centered=(True, True, False))
        .rotate((0, 0, 0), (0, 1, 0), -angle_deg)
        .translate((-dx, 0, base_thk + sup_h)))

    solid = solid.cut(groove)
    solid = solid.clean()
    solid = cq.Workplane(obj=solid.val().heal())

    root_sel = cq.selectors.BoxSelector((-1.0, -base_wid/2, base_thk-0.5), (1.0, base_wid/2, base_thk+0.5))
    solid = solid.edges(root_sel).fillet(fillet_r)

    top_z = base_thk + sup_h
    top_sel = cq.selectors.BoxSelector((-base_len, -base_wid/2, top_z-0.5), (base_len, base_wid/2, top_z+0.5))
    solid = solid.edges(top_sel).chamfer(chamfer_r)

    base_front_sel = cq.selectors.BoxSelector((base_len-0.5, -base_wid/2, -0.5), (base_len+0.5, base_wid/2, 0.5))
    solid = solid.edges(base_front_sel).chamfer(chamfer_r)

    return solid

model = build_model()
```

工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽量简洁，方便 3D 打印。
- 设计摘要：设计一款一体式极简桌面手机支架。底座为长80mm、宽60mm、厚4mm的矩形平板，确保打印附着面平整。背部支撑板从底座后缘向上延伸，高度110mm，与底座呈60度夹角，提供舒适的竖屏观看视角。支撑板顶部设有一道宽12mm、深5mm的U型凹槽用于卡住手机底部边缘，防止前滑。所有直角连接处均添加半径3mm的圆角过渡以分散应力。整体壁厚保持3mm，无大于45度的悬垂结构，实现免支撑FDM打印。
- 对象类型：桌面手机支架
- 目标尺寸（mm）：长 80.00，宽 60.00，高 110.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.35
- 固定边界盒：[0.0, -30.0, -55.0, 0.0, 30.0, 55.0]
- 加载边界盒：[80.0, -30.0, -55.0, 80.0, 30.0, 55.0]
- 试探载荷向量（N）：[0.0, -5.0, 0.0]
- 设计目标：提供稳定60度竖屏视角; 一体成型免组装; 优化FDM打印工艺(免支撑/防翘曲); 结构轻量化且承重可靠
- 风格关键词：极简几何, 一体化成型, 无支撑设计, 现代桌面美学
- 视觉要求：整体轮廓流畅，背部支撑面与底座平滑过渡。边缘全部采用R2-R3倒角处理，消除锐利感。底部保持大面积平整，顶部卡槽边缘做微倒角防刮手。表面呈现干净的几何切面风格，无复杂镂空或装饰性纹理。
- 默认假设：1. 默认适配主流智能手机(厚度8-10mm, 重量约200g)，预设5N安全载荷余量。2. 观看角度设定为60度，符合人体工学竖屏视频习惯。3. 底座厚度4mm，主体壁厚3mm，满足FDM打印强度要求。4. 关键受力根部预设R3圆角防断裂。5. 整体几何控制在45度打印倾角内，无需额外支撑结构。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq
import math

def build_model():
    # 参数定义
    base_len, base_wid, base_thk = 80.0, 60.0, 4.0
    sup_thk = 3.0
    angle_deg = 60.0
    slot_w, slot_d = 12.0, 5.0
    fillet_r = 3.0

    # 几何计算
    sup_len = 110.0 / math.sin(math.radians(angle_deg))
    dx = sup_len * math.cos(math.radians(angle_deg))
    top_x, top_z = -dx, base_thk + 110.0

    # 支撑板背面偏移向量 (垂直于支撑面，向外)
    nx, nz = math.cos(math.radians(30)), math.sin(math.radians(30))
    p_back_start = (0 + sup_thk * nx, base_thk + sup_thk * nz)
    p_back_end = (top_x + sup_thk * nx, top_z + sup_thk * nz)

    # 构建2D轮廓 (XZ平面)
    profile = (cq.Workplane("XZ")
        .moveTo(0, 0)
        .lineTo(base_len, 0)
        .lineTo(base_len, base_thk)
        .lineTo(0, base_thk)
        .lineTo(top_x, top_z)
        .lineTo(p_back_end[0], p_back_end[1])
        .lineTo(p_back_start[0], p_back_start[1])
        .close())

    # 拉伸为实体
    solid = profile.extrude(base_wid).translate((0, -base_wid / 2, 0))

    # 根部倒角 (仅对平行于Y轴的轮廓边进行倒角，避免影响顶面)
    solid = solid.edges("|Y").fillet(fillet_r)

    # 顶部U型凹槽
    groove = cq.Workplane("XZ").box(sup_thk + 1, slot_w, slot_d, centered=(True, True, False))
    groove = groove.translate((top_x, 0, top_z))
    groove = groove.rotate((top_x, 0, top_z), (0, 1, 0), 30)
    solid = solid.cut(groove)

    # 顶部边缘微倒角防刮手
    solid = solid.edges("|Y and >Z").fillet(1.0)

    return solid

model = build_model()
```

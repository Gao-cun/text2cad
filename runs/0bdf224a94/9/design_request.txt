工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 1. 主轮廓 (XZ平面) - 45度自支撑斜面 + 底部限位 + 顶部挡边
    # 修复原代码中重叠/零长线段导致的 OCC 内核崩溃 (Segfault -11)
    profile = cq.Workplane("XZ") \
        .moveTo(0, 0) \
        .lineTo(110, 0) \
        .lineTo(110, 10) \
        .lineTo(90, 10) \
        .lineTo(20, 80) \
        .lineTo(10, 80) \
        .lineTo(10, 90) \
        .lineTo(20, 90) \
        .lineTo(20, 80) \
        .lineTo(0, 10) \
        .lineTo(0, 0) \
        .close()

    width = 100.0
    model = profile.extrude(width)

    # 2. 防滑凸点阵列 (安全合并策略)
    # 斜面中心约在 X=55, Z=45。绕Y轴旋转45度贴合斜面
    slope_center = (55, 0, 45)
    slope_wp = cq.Workplane("XZ").transformed(rotate=(0, 45, 0), offset=slope_center)

    # 生成点阵 (避开边缘，确保完全落在实体内)
    pts = [(x, y) for x in range(-20, 21, 6) for y in range(-20, 21, 6)]
    # 增加圆形边界过滤，防止凸点超出斜面边界导致布尔运算失败
    pts = [(x, y) for x, y in pts if (x**2 + y**2) < 300]

    bumps = slope_wp.pushPoints(pts).circle(1.0).extrude(0.6)
    model = model.union(bumps)

    # 3. 边缘倒角 (消除应力集中，提升打印质量与手感)
    # 采用单一明确选择器批量处理，避免多次调用 fillet 导致拓扑冲突或内核崩溃
    model = model.edges(">Z or |Y").fillet(1.5)

    # 4. 拓扑清理与流形验证
    model = model.clean()
    return model
```

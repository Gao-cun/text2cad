工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 核心设计参数 (单位: mm)
    L, W, H = 120.0, 100.0, 130.0
    base_h = 10.0

    # 1. 主体轮廓 (XZ平面) - 修正原代码连续重复点导致的 BRep_API 拓扑崩溃
    # 采用显式链式调用构建闭合多边形，确保几何流形
    main_body = (
        cq.Workplane("XZ")
        .moveTo(0, 0)
        .lineTo(L, 0)
        .lineTo(L, base_h)
        .lineTo(0, H)
        .lineTo(0, 0)
        .close()
        .extrude(W)
    )

    # 2. 底部限位挡边 (防手机滑落)
    # 语义修正：挡边应位于背部垂直面底部，向前延伸以承托手机
    lip_d, lip_h, lip_w = 6.0, 8.0, 80.0
    lip_y_start = (W - lip_w) / 2
    lip = cq.Workplane("XZ").box(lip_d, lip_h, lip_w).translate((lip_d/2, base_h, lip_y_start + lip_w/2))
    model = main_body.union(lip)

    # 3. 防滑凸点阵列 (位于背部倚靠面，向 -X 方向突出 1mm)
    bump_list = []
    for z in range(30, 110, 15):
        for y in range(20, 80, 15):
            bump = cq.Workplane("YZ").circle(1.0).extrude(-1.0).translate((0, y, z))
            bump_list.append(bump)
    if bump_list:
        model = model.union(*bump_list)

    # 4. 边缘倒角处理 (R=2.0mm)
    # 仅对平行于Y轴的长边进行倒角，避免短边/复杂交线引发 OpenCASCADE 倒角失败
    # 满足 3D 打印应力释放与手感要求
    model = model.edges("|Y").fillet(2.0)

    # 5. 几何清理
    model = model.clean()
    return model
```

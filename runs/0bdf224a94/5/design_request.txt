工程基线说明
- 原始需求：我要一个桌面手机支架，适合竖放看视频，结构尽 量简洁，方便 3D 打印。
- 设计摘要：采用一体化L型或斜面支撑结构，底部宽大稳固，背部设有限位与防滑特征，整体避免复杂装配与悬垂结构，以优化FDM打印成功率。
- 对象类型：手机支架
- 目标尺寸（mm）：长 120.00，宽 100.00，高 130.00
- 材料：PLA，杨氏模量 3500.00 MPa，泊松比 0.36
- 固定边界盒：[0.0, 0.0, 0.0, 120.0, 100.0, 10.0]
- 加载边界盒：[30.0, 30.0, 50.0, 90.0, 70.0, 110.0]
- 试探载荷向量（N）：[0.0, 0.0, -4.9]
- 设计目标：稳固支撑竖屏手机; 结构简洁易打印; 减少或消除打印支撑; 防滑防倾倒
- 风格关键词：极简, 几何, 实用主义, 一体化
- 视觉要求：表面平整光滑，减少层纹视觉干扰; 边缘采用适度倒角处理以提升手感与安全性; 无复杂浮雕或外露纹理，保持极简几何外观; 整体呈现单色/哑光质感
- 默认假设：默认适配主流智能手机（宽度70-80mm，厚度8-10mm）; 假设打印方向为Z轴向上，底座平放于构建板，无需额外支撑结构; 试探性载荷按单部手机约0.5kg重力垂直向下施加于背部支撑区域; 结构为单件一体成型，不包含活动铰链、螺丝或二次装配
- 执行说明：以上边界盒、试探载荷和材料参数是当前求解后端的默认分析上下文，不是造型本身的唯一解；若你为了更符合真实物体语义而调整几何，请在 self_check_notes 中说明。
- 约束：必须生成可执行的 CadQuery 代码，几何应可网格化、可渲染、可进入后续力学和视觉审查。

```python
import cadquery as cq

def build_model():
    # 1. 主体轮廓 (XZ平面) - 45度自支撑斜面 + 顶部限位挡边
    profile = cq.Workplane("XZ") \
        .moveTo(0, 0) \
        .lineTo(120, 0) \
        .lineTo(120, 10) \
        .lineTo(100, 10) \
        .lineTo(30, 80) \
        .lineTo(30, 90) \
        .lineTo(36, 90) \
        .lineTo(36, 80) \
        .lineTo(42, 80) \
        .lineTo(100, 10) \
        .lineTo(100, 0) \
        .close()

    # 挤出主体，宽度80mm，居中于Y轴 (底座总宽100mm)
    support_width = 80.0
    model = profile.extrude(support_width).translate((0, (100 - support_width) / 2, 0))

    # 2. 防滑凸点阵列 (精确贴合45度斜面)
    # 创建与斜面平行的局部工作平面
    slope_wp = cq.Workplane("XZ").transformed(rotate=(0, 45, 0))
    pts = [(x, y) for x in range(-20, 21, 10) for y in range(-30, 31, 10)]
    # combine=True 确保所有凸点融合为单一实体，彻底解决多体/非流形报错
    bumps = slope_wp.pushPoints(pts).circle(1.5).extrude(0.8, combine=True)
    # 平移至斜面中心位置
    bumps = bumps.translate((65, 0, 45))

    # 布尔并集
    model = model.union(bumps)

    # 3. 边缘倒角 (缓解应力集中，提升手感与安全性)
    # 针对外露锐边进行倒角，避开内部复杂交线以防拓扑错误
    model = model.edges(">Z or <Z or |X or |Y").fillet(2.0)

    # 4. 几何清理与流形验证
    model = model.clean()
    return model
```
